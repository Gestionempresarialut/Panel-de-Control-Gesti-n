Conectar con GitHub

Para publicar cambios el panel necesita una llave de acceso (token) de GitHub. Solo se pide una vez por computadora.

¿Cómo obtengo la llave? (5 minutos)
  1. Entra a github.com/settings/personal-access-tokens/new con la cuenta .
  2. En Token name escribe algo como Panel Gestión Empresarial y elige una fecha de vencimiento (por ejemplo, 1 año).
  3. En Repository access elige Only select repositories y selecciona .
  4. En Permissions → Repository permissions, busca Contents y cámbialo a Read and write.
  5. Baja hasta el final, haz clic en Generate token y copia la llave (empieza con github_pat_).
  6. Pégala aquí abajo. ⚠️ No la compartas por correo ni redes: quien la tenga puede modificar el sitio.

¿Seguro?
Ver como Así se verá el sitio con tus cambios. Todavía no se publica nada.
